Tổng quan

Thứ tự lúc khởi động: mở hai cổng, xung SWON, rồi query trạng thái lần đầu.

Đọc hình

  • Khi cửa sổ Loaded, InitComConnections mở lần lượt RF Gateway rồi Control Box (đều trên luồng nền).
  • Mở cổng RF thành công thì OpenGeneration tăng; mở Control Box thì chạy xung SWON (Motor 1..4 = RUN, rồi Start All HIGH 500 ms → LOW) dưới khóa _controlBoxGate.
  • Nếu một cổng chưa lên (driver USB chưa sẵn sàng lúc khởi động cùng Windows), MainWindow thử lại tới 12 lần, mỗi 5 s.
  • Vòng polling thấy OpenGeneration đổi, đợi 2,5 s (gateway có thể reboot) rồi query mọi hộp đang dùng theo vòng (xem Status Polling). Hộp chạy firmware v2 trả lời sau khoảng 20 ms; hộp vẫn im sau PollRetries vòng (mỗi vòng ít nhất PollRoundWaitMs = 5 s) thì hiện Offline.
