Thư mục project ESDCMS/; ba nhóm file: thiết bị & logic (Device/), bản đồ băng tải (Monitoring/), và cửa sổ chính.

FileVai trò
ESDCMS.csproj / ESDCMS.slnxProject .NET Framework 4.8 · WPF · x64, ra ESDCMS.exe; mở solution bằng Visual Studio 2022 hoặc dotnet build.
App.xaml.csKhởi động: tên hiển thị AppDisplayName, single-instance mutex, bắt lỗi toàn cục → .esdcms\crash.log, watchdog thoát.
MainWindow.xaml(.cs)Cửa sổ: nút ngôn ngữ, khung trang giám sát, console log, thanh dưới (group RF Gateway / Control Box / Cloud với nút cài đặt ⚙, group Motors), Lock, auto refresh COM khi cắm/rút USB.
SettingsForm.csHộp thoại cài đặt dựng bằng code cho các nút ⚙ của thanh dưới (COM, Net ID, các thời gian, Firebase).
Device/CloudUploader.cs, Device/FirebaseRest.csGhi line lên Firebase (đăng nhập, PATCH, gửi bù khi mất mạng) và tên lỗi kiểu mã + tên, xem Devices & Roles.
Lang/Strings.{en,ko,th}.xaml, Lang/Lang.csChữ giao diện cho English / 한국어 / ไทย (cùng bộ khóa) và lớp đổi ngôn ngữ lúc chạy.
Device/PortNames.csGiá trị của combo COM: tên cổng thật thì mở, Close (và giá trị cũ Unused/Unset) thì không.
Images/icon/Icon ESD dạng vector esd.svg, file esd.ico và script make_esd_icon.ps1 sinh ra app.ico.
UnlockDialog.csHộp nhập mật khẩu khi mở khóa; nhập đúng một lần thì nhớ trong bộ nhớ tới khi tắt app (EnteredThisSession). Exe chỉ giữ mã băm SHA-256 (có salt) của mật khẩu; đổi mật khẩu = thay hằng PasswordHash. Chống lỡ tay, không phải bảo mật mạnh.
Device/ViewModel.csTrái tim: parser khung LoRa, 20 ESDBox, vòng polling, timer + luật dừng băng tải.
Device/ControlBox.csCổng Control Box: dựng khung lệnh, ghi, chờ echo, kiểm ACK.
Device/RFGateway.csCổng RF Gateway: mở/đóng, gửi khung query, phát sự kiện nhận.
Device/DeviceManagerPage.xaml.csGiữ ControlBox + RFGateway; áp/ngắt kết nối, refresh danh sách COM, xung SWON lúc mở.
Device/SerialPortSafe.csMở/đóng cổng an toàn chống treo (xem trang Connections).
Device/Config.cs, AppConfig.csCác khóa cấu hình + giá trị hiệu lực (clamp). Xem Config.
Device/ConfigStore.csĐọc/ghi %USERPROFILE%\.esdcms\config.json (lần đầu chép config cũ cạnh exe sang), an toàn với mất điện giữa chừng.
Device/ESDBox.cs, DeviceStatus.csMột hộp và enum trạng thái; màu theo trạng thái.
Device/AutoStart.csBật/tắt chạy cùng Windows (giá trị ESDCMS trong HKCU\…\Run); xóa giá trị cũ ESDKitSystem.
Device/UiLogWriter.csChuyển Console.WriteLine thành dòng trong panel log.
Monitoring/MornitorPage.xaml(.cs)Trang giám sát: tạo RootCanvas, nối click ô → query hộp; đặt dải cảnh báo Offline ngay dưới hàng ô, rộng bằng dải băng tải.
Monitoring/RootCanvas.csVẽ băng tải: 20 ô vị trí + 20 ô hộp, nạp layout từ config.
Monitoring/BlockDevice.csMột ô hộp: kéo đổi vị trí, phải-chuột bật/tắt dùng, click để hỏi.
HexByteConverter.csHiển thị/nhập Network ID dạng hex hai chữ số.

Fody / PropertyChanged

Project dùng Fody + PropertyChanged.Fody: các auto-property trong ViewModel, ESDBox tự được dệt OnPropertyChanged lúc build. Không tự viết OnPropertyChanged trong setter. Mã nguồn là bản dịch ngược từ exe rồi dọn lại để build, tên biến cục bộ lấy từ PDB nên khá sát bản gốc.
