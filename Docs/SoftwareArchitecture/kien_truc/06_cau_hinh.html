Tổng quan

Một file config.json trong thư mục của user Windows giữ cổng COM, các thông số thời gian và layout màn hình.

Đọc/ghi qua ConfigStore, tại %USERPROFILE%\.esdcms\config.json (cùng chỗ với crash.log). Không đặt cạnh exe — thư mục cài có thể chỉ đọc (Program Files) hoặc bị thay khi cập nhật; cũng không theo thư mục hiện hành — chạy từ shortcut/auto-start thì thư mục có thể khác và cấu hình "biến mất". File không có sẵn trong repo; app tạo lần chạy đầu.

Chuyển từ bản cũ

Bản trước (ESDKitSystem.exe) để config.json cạnh exe. Lần đầu ESDCMS chạy, nếu trong .esdcms chưa có file mà cạnh exe còn file cũ, nó đọc file cũ rồi ghi sang chỗ mới (file cũ để nguyên) — cổng COM và layout được giữ.

Một user, một cấu hình

Mọi bản ESDCMS chạy dưới cùng một user Windows dùng chung file này, dù exe nằm ở thư mục khác nhau. Muốn hai line trên một PC với hai bộ cổng COM khác nhau thì cần hai user Windows.

json · %USERPROFILE%\.esdcms\config.json
{
  "Com": {
    "RFGatewayCOM": "COM5",
    "ControlBoxCOM": "COM6",
    "AutoStart": true,
    "LogCollapsed": false,
    "Language": "en",
    "PollReplyTimeoutMs": 400,
    "PollRoundWaitMs": 5000,
    "PollRetries": 3,
    "AskAgainSec": 120,
    "TxGapMs": 500,
    "NetworkID": 3,
    "TxTimeoutMs": 500,
    "TxRetries": 4,
    "TxRetryDelayMs": 100
  },
  "Monitoring": {
    "DevicePosition":  [0,1,2, ... ,19],
    "DevicesIsActive": [true,true,true,true,true,true,true,true,false, ... ]
  }
}

Các khóa (mục Com)

KhóaMặc địnhHiệu lực (clamp)Ý nghĩa
RFGatewayCOM / ControlBoxCOM——Tên cổng COM, chọn ở combo của group (chọn là kết nối); Close = không mở. Giá trị cũ Unused/Unset cũng được hiểu là Close.
Languageenen / ko / thNgôn ngữ giao diện, đổi bằng nút ngôn ngữ trên thanh tiêu đề; console log vẫn tiếng Anh
NetworkID3 (0x03)—Line ID chấp nhận từ RF Gateway; khung ID khác bị bỏ — ô Net ID, group RF Gateway
PollReplyTimeoutMs400≥ 100Thời gian nghe trả lời sau một query, trước khi gửi query kế
PollRoundWaitMs5000≥ 1000Một vòng hỏi kéo dài ít nhất chừng này (trừ khi mọi hộp đã trả lời) rồi mới hỏi lại các hộp còn im. Không có ô trên giao diện, chỉ sửa trong file. Từ v2.1
PollRetries3≥ 1Số vòng hỏi trước khi cho Offline (gồm vòng đầu)
AskAgainSec1200, hoặc ≥ 5Chu kỳ hỏi lại mọi hộp đang dùng; 0 = không — ô Ask again, group RF Gateway. Trước v2.1 mặc định là 300; giá trị đã lưu trong file được giữ nguyên nên khi cập nhật phải tự đặt lại
TxGapMs500≥ 0Khoảng cách giữa hai lệnh Control Box liên tiếp — ô TX gap, group Control Box
TxTimeoutMs500≥ 50Chờ echo Control Box trước khi coi lệnh thất bại — ô RX timeout, group Control Box
TxRetries4≥ 1Số lần gửi một lệnh Control Box trước khi bỏ (gồm lần đầu) — ô Retry, group Control Box
TxRetryDelayMs100≥ 0Khoảng cách giữa hai lần gửi cùng một lệnh Control Box — ô Retry gap, group Control Box
AutoStart / LogCollapsedtrue / false—Chạy cùng Windows; ẩn panel log

Giá trị trong file được "clamp" khi dùng (ví dụ PollReplyTimeoutMs nhỏ hơn 100 vẫn coi là 100), nên không đặt được giá trị nguy hiểm. Các ô trên thanh cài đặt ghi lại file khi mất focus và log đúng khóa vừa đổi.

Mục Monitoring & layout

DevicePosition[20] là vị trí (0..19) của từng hộp trên băng tải, DevicesIsActive[20] là hộp nào đang dùng. Mặc định 8 hộp đầu bật, còn lại tắt. ConfigStore tự chuẩn hóa: đủ 20 phần tử và vị trí không trùng.

Ghi an toàn

  • Ghi nguyên tử: ghi ra config.json.tmp rồi thay (File.Replace) — mất điện giữa chừng không để lại file hỏng.
  • File hỏng: đọc lỗi thì sao lưu thành config.json.bad-<thời gian> và chạy bằng mặc định, không chặn khởi động.
  • Auto-start: ghi giá trị ESDCMS trong HKCU\…\Run, viết lại mỗi lần chạy nên theo đúng exe nếu đổi thư mục; giá trị cũ ESDKitSystem (bản trước) bị xóa để Windows không mở exe cũ.
