Tổng quan

Hai trang khung tin: khung trạng thái LoRa qua RF Gateway (cả chiều query), và khung lệnh Control Box có echo xác nhận cùng bản đồ chân relay.

TrangNội dung
LoRa Status ProtocolKhung AA..BB qua RF Gateway: byte, CRC8, Network ID, khung trạng thái hộp gửi lên và khung query ‘?’ PC gửi xuống.
Control Box ProtocolKhung 44 45 .. 56 tới Arduino: opcode kênh, STATE, checksum XOR, echo làm ACK; bản đồ chân và logic relay NC.
